# GBoS GEOAI — Soil Health & Land Degradation

This folder contains the Google Earth Engine Code Editor JavaScript source for the GBoS GEOAI Soil Health & Land Degradation Intelligence dashboard for The Gambia.

## Open and run in Google Earth Engine

1. Open https://code.earthengine.google.com/
2. Create a new script.
3. Open `Gambia_Soil_Health_Land_Degradation.js` in this repository and copy its contents into the Earth Engine Code Editor.
4. Confirm that your account has access to the asset configured in the script:
   `projects/ee-aishaansu80/assets/GambiaEA_Final1`
5. Click **Run** in the Code Editor.

## Open in Visual Studio Code

1. Open this repository in GitHub and choose **Code → Download ZIP**, or clone it with Git.
2. Open the downloaded folder in Visual Studio Code.
3. Open `gee/Gambia_Soil_Health_Land_Degradation.js` to edit the source.
4. Commit and push changes to publish updated source to GitHub.

## Important

This is an Earth Engine Code Editor application, not a standalone HTML website. Its `ui.*`, `ee.*`, and `Export.*` calls run in Google Earth Engine. Uploading the JavaScript to GitHub shares the source code but does not itself execute the dashboard as a GitHub Pages website. The indices and composite indicators are remote-sensing screening proxies and require field/laboratory validation for quantitative soil assessment.
