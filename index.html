Methodology

Geographic filters come from the uploaded Census EA boundaries. Built-up features are assigned using centroid-in-polygon screening. If a verified hectare field is unavailable, area is estimated geodesically from the polygon geometry. The new-built-up layer uses centroid screening, not exact polygon subtraction.
