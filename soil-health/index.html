Geospatial research prototype · 2026

Soil health, land degradation and environmental indicators

An Earth Engine research dashboard designed to explore satellite-derived environmental indicators across The Gambia. The Code Editor script combines Sentinel-2, Sentinel-1, CHIRPS rainfall and terrain information to screen spatial patterns.

Indicators include a soil-health proxy, land-degradation proxy, erosion-risk screening, vegetation indices, moisture-related indices, rainfall and radar response. These are remote-sensing proxies, not field-validated soil measurements.

Workflow

  1. Open the preserved JavaScript source in the Earth Engine Code Editor.
  2. Run and validate the analysis, selectors, chart, legend, map layers and exports.
  3. Publish a public Earth Engine App from the Code Editor Apps panel.
  4. Set the published app URL in app-config.js and enable GitHub Pages for this repository.

Interpretation and limitations

  • Indicators are screening proxies and should not be presented as laboratory-measured soil properties.
  • Season, cloud cover, sensor availability, spatial resolution and masking affect the results.
  • Validate outputs against field observations and local expert knowledge before operational decisions.
  • Public Apps can expose their source and asset identifiers; do not publish private or sensitive information.
Data access requirement: The script references the Earth Engine asset projects/ee-aishaansu80/assets/GambiaEA_Final1. Before publication, confirm that the published App can read this asset. Share it only as permitted by its data owner and applicable GBoS data-sharing rules.
